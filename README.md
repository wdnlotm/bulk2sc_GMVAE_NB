# bulk2sc_GMVAE_NB
This repository was created by mirroring the [bulk2sc_GMVAE](https://github.com/wdnlotm/bulk2sc_GMVAE) repository, with the zero-inflated negative binomial (ZINB) distribution replaced by a negative binomial (NB) distribution.

Unlike the original `bulk2sc_GMVAE` repository, `bulk2sc_GMVAE_NB` has not yet been fully tested.
